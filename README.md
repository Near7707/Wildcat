# Wildcat

SillyTavern 확장. 그림 상점 **The Honest Wildcat**에서 내가 등록한 그림을 AI 손님들이 감상하고 반응하는 작은 픽셀 게임입니다.

> 개발 중 (0.1.8 — 1단계 진행 중). 지금은 작품 등록·목록·원본 보기, 비전 AI 관찰, 손님 만들기, 손님 감상(초안)까지 됩니다.

## 필요한 것
- SillyTavern 1.19.0 이상 (연결 프로필 기능)
- 연결 프로필 1개 이상
  - **비전 AI**: Chat Completion 방식이고 그림을 볼 수 있는 모델
  - **반응 AI**: 아무 모델이나 가능
  - 두 칸에 같은 프로필을 골라도 됩니다.
- Vertex로 연결한 프로필은 지금 SillyTavern에서 이 방식의 요청이 실패해서 쓸 수 없습니다.

## 설치
1. SillyTavern에서 확장 메뉴 → **Install extension**을 누릅니다.
2. 이 주소를 넣습니다: `https://github.com/Near7707/Wildcat`
3. 확장 메뉴에서 **Wildcat**을 엽니다.

업데이트는 확장 관리 화면에서 Wildcat의 업데이트 버튼을 누르면 됩니다.

## 사용
1. 비전 AI, 반응 AI 프로필을 고릅니다.
2. **연결 시험**으로 각각 확인합니다.
3. **가게 열기**로 전체화면 창을 엽니다. (닫기 버튼 또는 Esc로 닫기)
4. **작품 등록**으로 그림을 올립니다. 작품을 누르면 원본을 크게 볼 수 있고, 제목 바꾸기와 삭제도 여기서 합니다.
5. 등록하면 비전 AI가 그림을 보고 관찰 결과를 남깁니다. 작품 → **관찰**에서 결과를 보고 다시 관찰할 수 있습니다. 그림은 긴 변 1216px로 줄여서 한 번만 보냅니다.
6. **손님**에서 손님을 부를 수 있습니다. 게임이 출신 세계·직업·성격·취향·외형을 무작위로 정하고, 반응 AI가 이름과 짧은 소개를 짓습니다. 손님마다 반응 AI를 한 번 부릅니다. (1단계 시험 화면이라 숨은 성격도 보입니다)
7. 손님을 눌러 **그림 보게 하기**를 하거나, 작품 → **감상**에서 **안 본 손님 전원 감상**을 누르면 손님들이 그림을 봅니다. 손님마다 겉말(없을 수도 있음), 속마음, 관심(없음/조금/큼), 갖고 싶은지를 남깁니다. 반응 AI에는 그림 대신 관찰 결과만 보냅니다. 지금은 초안이라 방명록에는 아직 남지 않습니다.

## 저장 위치
게임 기록은 SillyTavern 서버의 사용자 파일 폴더(`data/<사용자 이름>/user/files/`)에 `wildcat_`로 시작하는 이름으로 저장됩니다. PC와 폰 어디서 열어도 같은 가게가 보입니다.
- `wildcat_state.json` — 가게 상태 (작품 목록, 지금 있는 손님, 골드, 게임 시각)
- `wildcat_book_<작품ID>.json` — 작품별 방명록
- `wildcat_ledger.json` — 판매 장부
- `wildcat_img_<작품ID>.<확장자>` — 작품 그림
- `..._bak.json` — 저장 직전 내용 백업

확장 메뉴의 **저장 점검** 버튼으로 저장이 잘 되는지 확인할 수 있습니다. (시험 파일만 쓰고 지웁니다)
